標準ライブラリのみで動く Python/bash スクリプトを、cron スケジュールで定期実行します。 ネットワークアクセスは可能ですが pip install はできません (bashには curl も入っていないため、代わりに download URL 保存先パス [User-Agent] 関数が常に使えます。 中身はpython3のurllibを1回呼ぶだけです)。1回の実行は5分でタイムアウトし、 リトライや多重実行 (前回の実行が終わっていない場合はスキップ) は行いません。 ピアノードにはコードとスケジュールのみ同期され、常に無効状態で作成されます (同じ処理がノード数分実行されるのを防ぐため) — 各ピアで実行したい場合はそのノード側で個別に有効化してください。

例: */5 * * * * (5分ごと) ・ 0 3 * * * (毎日3時) ・ @hourly ・ @daily

From/Toを入力すると、コードタブの中で SUBJECT/BODY変数を 自分で組み立てたうえで、Pythonなら send_mail(TO_ADDR, SUBJECT, BODY)、 bashなら send_mail "$TO_ADDR" "$SUBJECT" "$BODY" を呼ぶだけでメール送信できるように なります (SMTPサーバー自体の接続情報は/configで設定してください)。 bash側のsend_mailは内部でpython3を1回呼び出します (curl入りの軽量イメージが手元にないため)。 使わない場合はここは両方とも空欄のままでOKです。 

SUBJECT = "件名"
BODY = "本文"
send_mail(TO_ADDR, SUBJECT, BODY)

download はcurlが無い代わりのヘルパーで、bashジョブなら メール送信タブを使っていなくても常に使えます (中身はpython3のurllib)。 

download "https://api.example.com/status.json" "/tmp/status.json"
COUNT=$(python3 -c "import json; print(json.load(open('/tmp/status.json'))['count'])")
SUBJECT="status check: $COUNT items"
BODY="fetched at $(date)"
send_mail "$TO_ADDR" "$SUBJECT" "$BODY"
